تشغيل الموقع محلياً
===================
1) ويندوز: انقر مرتين على run.bat  (يفتح المتصفح تلقائياً)
   ماك/لينكس: نفّذ  ./run.sh
2) أو يدوياً من الطرفية داخل هذا المجلد:
      python -m http.server 8000
   ثم افتح  http://localhost:8000/login.html

مهم:
- لا تفتح index.html بالنقر المزدوج (file://) فتسجيل الدخول لن يعمل. استعمل http://localhost:8000
- localhost مسموح تلقائياً في Firebase Authentication، فلا تحتاج إضافته.
- نشر قواعد قاعدة البيانات (database.rules.json) يتم يدوياً من لوحة Firebase.
- الموقع يعمل من حاسوبك فقط. لن يعمل الدخول من هاتف عبر عنوان IP الشبكة.
